## 1.0.2

### Patch Changes

- bb27b64: Bump all devDependencies to latest. Notably `@sanity/pkg-utils` 10 → 12, which required removing the now-default `dts: 'rolldown'` option and disabling the new TSDoc/`@public` release-tag check (`tsdoc: false`) in `package.config.ts`, since this package doesn't tag exports with release tags. `typescript` stays pinned to `^6.0.3` until `typescript-eslint` supports TypeScript 7.

## 1.0.0

### Major Changes

- Initial release: typed page-builder dispatcher (`createPageBuilder`), section
  modules, framework-agnostic render loop, parity helpers, and icon map.
- Tooling: ESLint (flat config) + Prettier with a husky pre-commit hook running
  lint-staged, `knip` for unused-code detection, and GitHub Actions CI (lint,
  format, type-check, knip, test, build) + Dependabot.

Releases after 1.0.2 are generated by semantic-release from commit messages:
edit those, not this file. 1.0.0 and 1.0.2 were written with Changesets.
