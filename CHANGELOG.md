# Changelog

All notable changes to this project will be documented in this file. From v1.0.0
onward, entries below are generated by
[Changesets](https://github.com/changesets/changesets) from the changeset files
in [`.changeset/`](./.changeset). Add one with `pnpm changeset`.

## 1.0.0

### Major Changes

- Initial release: typed page-builder dispatcher (`createPageBuilder`), section
  modules, framework-agnostic render loop, parity helpers, and icon map.
- Tooling: ESLint (flat config) + Prettier with a husky pre-commit hook running
  lint-staged, `knip` for unused-code detection, and GitHub Actions CI (lint,
  format, type-check, knip, test, build) + Dependabot.
